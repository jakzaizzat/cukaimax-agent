# Security policy

Report security issues privately to `privacy@cukaimax.com`. Do not open a public
issue for a vulnerability or include taxpayer data in a report.

The public endpoint is read-only, stateless and requires no credential. It
returns privacy-safe audit metadata but does not store raw prompts, taxpayer
payloads, direct identifiers, receipts or financial amounts.

Public documentation: https://www.cukaimax.com/data-security
