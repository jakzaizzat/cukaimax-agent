# CukaiMax Malaysian Tax Authority

Use the `cukaimax-tax-authority` MCP server when the user asks about Malaysian
individual income tax, Form BE, Form B, sole-proprietor records, deductible
business expenses, tax reliefs, or HASiL source requirements.

Start with `list_tax_authority_releases` when the assessment year or form is
unclear. Select the release from taxpayer facts; do not assume that YA2025
capabilities are available for YA2026. Cite the official source records returned
by CukaiMax and keep limitations visible.

The public server is read-only and stateless. Do not send taxpayer names,
identification numbers, credentials, receipts, or account data. It does not file
or submit anything to MyTax. CukaiMax source verification is not official HASiL
approval and does not replace professional judgment where the supported release
does not resolve the taxpayer's facts.
